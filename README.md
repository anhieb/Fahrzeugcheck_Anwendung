# Fahrzeugcheck_Anwendung

## Worum geht es bei dieser Anwendung?
Es soll eine C# Anwendung werden, womit man Fahrzeugchecks im Rettungsdienst durchführen kann.

## Warum baue ich sie?
Ein Uniprojekt. Aktuell wird im Rettungsdienst häufig mit Zetteln gearbeitet. Diese werden abgearbeitet und anschließend in einem Ordner verstaut. Niemand schaut sich den Ordner an und dadurch fällt auch nciht auf, ob die Checks zuletzt vorgenommen wurden. Außerdem kann es passieren das der Ablauf von HU und AU übersehen wird bzw. zu spät bemerkt wird.

## Was soll die Anwendung können?
- Fahrzeuge anlegen
- Check nach Wolke(n) Schema durchführen (Wasser, Öl, Luft, Kraftstoff, Elektrik, (Notfallausrüstung)
- HU/ AU Termin eintragen mit Erinnerung zb 1 Monat vorher
- Rettungsrucksack auf Inhalt überprüfen
- Medikamente checken auf Vollständigkeit und Ablaufdatum
- optional: weitere Dinge zum abhaken, checken sollen hinzugefügt werden können.

## Technologien
(WPF, .NET 8, C#, MVVM, CommunityToolkit.Mvvm, JSON)
