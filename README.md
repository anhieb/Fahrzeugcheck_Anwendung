# Fahrzeugcheck_Anwendung

## Worum geht es bei dieser Anwendung?
Es soll eine C# Anwendung werden, womit man Fahrzeugchecks im Rettungsdienst durchführen kann.
Ob alles mit dem Fahrzeug (zb RTW, KTW) in Ordnung ist, technisch gesehen. Nach dem üblichen Schema Wolke. Rettungsrucksack und Medikamenten Checks sollen durchführbar sein.

## Warum baue ich sie?
Ein Uniprojekt

## Was soll die Anwendung außerdem noch können?
optional: weitere Dinge zum abhaken, checken sollen hinzugefügt werden können.

## Technologien
(WPF, .NET 8, C#, MVVM, CommunityToolkit.Mvvm, JSON)
